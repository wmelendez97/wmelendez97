## 👨‍💻 About me

I am a Systems Engineer with experience developing web applications for banking, government, and private-sector environments. I work across the stack, from responsive interfaces and UI/UX improvements to APIs, business logic, databases, and internal systems.

My approach combines clean code, practical problem solving, Agile collaboration, and a focus on delivering software that supports real business goals.

- 🚀 Developing internal systems for the banking sector.
- 🎨 Building responsive interfaces with Angular, React, and TypeScript.
- ⚙️ Supporting backend solutions with Spring Boot, Laravel, and PHP.
- 🗄️ Working with MySQL, PostgreSQL, and Oracle databases.
- 🤝 Applying Scrum and collaborative delivery practices.
- 🌎 Based in San Miguel, El Salvador.
